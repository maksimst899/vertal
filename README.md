VERTAL AI — интеллектуальный AI-ассистент для Windows с поддержкой локальных языковых моделей GGUF, llama.cpp, Hugging Face, голосового управления и поиска информации в интернете. Open Source проект, направленный на создание расширяемой AI-платформы.
